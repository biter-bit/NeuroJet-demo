* горизонтальное масштабирование

# 🛠 Проблемы и решения

### 🔧 Проблема 1 — высокая задержка API

**Решение:** кеширование Redis, оптимизация SQL, перенос тяжёлых операций в worker.

### 🔧 Проблема 2 — нестабильные внешние API

**Решение:** retry-политики, таймауты, circuit breaker, асинхронные адаптеры.

### 🔧 Проблема 3 — рост очередей в пиковые моменты

**Решение:** масштабирование worker-сервисов.

### 🔧 Проблема 4 — дублирование задач

**Решение:** идемпотентность обработчиков.
