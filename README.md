# 🛠 Проблемы и решения

### 🔧 Переход от монолита к микросервисам

**Проблема:** архитектура перестала масштабироваться.

**Решение:** разделение на сервисы → независимые релизы, ускоренная разработка.

---

### ⚙️ Оптимизация базы данных

**Проблема:** тяжёлые SQL-запросы тормозили API.

**Решение:** реорганизация схемы БД + переписывание запросов → время выполнения 30–40 мс.

---

### 🔥 Снижение нагрузки на БД

**Проблема:** PostgreSQL перегружался при пиках.

**Решение:** внедрение Redis → минус ~25% нагрузки.

---

### 🚀 Медленные релизы и сложные выкладки

**Проблема:** ручные деплои → долго, рискованно.

**Решение:** автоматизация через CI/CD → релизы за 3–5 минут.

---

### 🐳 Миграции без простоя

**Проблема:** изменения схемы в продакшене под нагрузкой.

**Решение:** продуманная последовательность миграций, feature-flip стратегии.
